# Frontières d'autorisation
Le prompt de lancement autorise les lots de code, tests simulés, dépendances isolées listées et builds locaux.
Il ne vaut pas autorisation d'activer le RSPdx, modifier un pilote, ouvrir le pare-feu, remplacer une installation tierce, publier ou écrire dans Nexus.
Demander uniquement au seuil concerné ; ne pas interrompre les parties indépendantes.
Un essai matériel nécessite appareil et réglages annoncés. Une capture réelle nécessite dossier et politique de conservation explicites.
Ne pas solliciter une nouvelle décision pour les defaults fixés dans S6 ; ne pas les modifier sans incompatibilité démontrée.
