# Transition projet existant

Analyser un projet deja commence sans modifier le code applicatif. Produire seulement les artefacts utiles : `CURRENT_STATE.md` pour l'etat transverse, `CODEBASE_MAP.md` si la navigation l'exige, un `task_state.yaml` compact pour le travail ouvert, puis les risques et la prochaine action prioritaire. Ne pas convertir les historiques en masse.
