# SR bootstrap 4.1

Use only for a non-trivial mutation, multi-lot execution or significant resume.

1. Read the nearest `AGENTS.md`.
2. State objective, assumptions, smallest sufficient approach and planned proof.
3. Inspect `PROJECT_PROFILE.yaml` only for a setting relevant to the task.
4. Select routes from `SR_ROUTES.json`; load only their sources.
5. Select zero to two skills from `SKILL_DIGEST.md` when an exact trigger applies.
6. Create `task_state.yaml` only when continuity is useful.

Mode `core` forbids MCP loading and calls. Mode `nexus_kg` additionally requires `MCP_POLICY.yaml`.
