# SR Harness 4.1

Use this harness for a validated multi-lot pass or long resume.

- group the smallest coherent set of lots;
- confirm order, dependencies, authority and final verification once;
- execute without micro-gates while scope remains stable;
- keep one compact task state and reference heavy evidence by path;
- stop for a real decision, threatened data, unsafe activation, unresolved dependency or handoff boundary.

`aurora-lot-runner` is the thin workflow router. Procedures and project sources remain authoritative.
