# UI visual QA

Read the project design direction, affected UI files and `ui_validation` configuration. Select only the changed routes and required viewports, then run the existing SR UI verifier.

Completion requires proportionate evidence for layout, browser errors, overflow and unexpected authentication redirects. If an authenticated or human-only path cannot be automated safely, report `user_testing` with a concrete checklist. Do not create a browser framework or unrelated snapshots.
