# Codex workflow — SR 4.1

```text
request
  -> classify simple / mutation / multi-lot / activation / resume
  -> load exact route
  -> inspect decisive source
  -> implement smallest complete change
  -> verify final result
  -> report evidence and limits
```

Simple questions and local edits stay on the fast path. Multi-lot work uses the harness. Build or deployment work uses the activation procedure only when explicitly requested.
