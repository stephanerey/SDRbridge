# Project skills policy — SR 4.1

Method skills are few and global; business skills stay local under `docs/codex/project-skills/`; runtime-agent skills stay in the product.

Load a skill only for its exact trigger. Do not export local business knowledge globally. Create a new domain skill only during bootstrap or after confirming that an important recurring rule has no suitable local skill.

Planning files, terminal compaction, final diff review, RepoMap maintenance and test selection are harness mechanics, not skills. SR 4.1 has no TDD skill.
