# Compact task state

Create `task_state.yaml` only when a non-trivial task benefits from continuity. Record objective, allowed scope, open requirements, decisions, evidence references, changed files, final verification and next action.

Do not copy logs, source files or full procedures into task state. Refer to heavy artifacts by stable path and hash.

Legacy `sr_contract.json`, `loop_contract.json` and five-file task memories remain readable. New V4.1 tasks do not need to reproduce them.
