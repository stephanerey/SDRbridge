# UI verification

Use only for a significant UI behavior or layout change.

- read the relevant design direction and changed UI files;
- select affected routes and required viewports only;
- use the existing SR UI verifier when safe;
- inspect page errors, console errors, overflow and unexpected auth redirects;
- use `user_testing` with a concrete checklist for a human-only or protected path.

Do not create a new browser framework or unrelated screenshots.
