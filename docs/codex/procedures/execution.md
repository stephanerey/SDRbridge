# Bounded execution

1. Select the validated task or pass.
2. Load only triggered procedures and relevant project sources.
3. Maintain one compact task state when continuity is useful.
4. Implement the smallest complete change.
5. Verify the final result proportionately.
6. Update structural maps only when structure changed.
7. Close with evidence, limits and remaining user acceptance.

Do not create intentional failures, duplicate contracts or automatic repair loops. After one corrected verification failure, diagnose the evidence before retrying.
